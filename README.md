# NEXO — Prototipo visual

Prototipo responsive del centro personal Nexo. No necesita instalar nada y no utiliza librerías externas.

## Probarlo
Abre `index.html` en el navegador.

## Publicarlo en GitHub Pages
1. Crea un repositorio nuevo.
2. Sube el contenido de la carpeta `NEXO` a la raíz.
3. Ve a **Settings → Pages**.
4. Selecciona **Deploy from a branch**.
5. Elige `main` y `/ (root)`.
6. Guarda y abre la dirección que genere GitHub.

## Importante
Es una maqueta. Los mensajes se muestran localmente y las acciones no modifican ningún servidor.
